CENTRAL DE CHAMADOS — INICIO RAPIDO

1. Extraia o ZIP para uma pasta nova.
2. Abra a pasta central-chamados no VS Code.
3. Abra o terminal nessa pasta e execute, um por vez:

   composer install
   php instalar.php
   php artisan serve

4. Acesse http://127.0.0.1:8000
